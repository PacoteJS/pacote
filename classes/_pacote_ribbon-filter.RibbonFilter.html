    Class RibbonFilter<T>

    A space-efficient, static probabilistic set for values with a stable toString().

    A Ribbon filter is built once from its complete set of elements and cannot be changed afterwards. Membership checks can produce false positives, at a rate of 2^-fingerprintBits, but never false negatives.

    This is a Standard Ribbon filter (Dillinger and Walzer, 2021) with a ribbon width of at most 32 bits. The filter uses seeded XXH64 hashing with enhanced double hashing by default. This hash is non-cryptographic and should not be used for security-sensitive purposes.

    Example

    import { optimal, RibbonFilter } from '@pacote/ribbon-filter'

    const filter = new RibbonFilter({
      ...optimal(0.01),
      elements: ['foo', 'bar'],
    })
    filter.has('foo') // => true
    filter.has('bar') // => true
    filter.has('baz') // => false
